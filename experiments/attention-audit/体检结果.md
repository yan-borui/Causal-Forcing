# Deep Forcing 的 30 层缓存体检

车间里多出的第二个人进入了历史缓存。第 0 层在下一次压缩就清空了该来源帧，整帧对首帧及提示词的相似度也落在候选分布中部。楼梯跳景前，全层平均 Sink 注意力处于相邻时间段的范围内。四例的层间排序相近。读取熵最高的层与保留历史来源最广的层相距很远，现有观测还不能决定应从哪一层调出名额。这次体检解释 Deep Forcing 的缓存行为。项目主表同时给出与 Causal Forcing 同权重普通滑窗、官方长视频方案的对照。[五种方法的配对比较](../official-long/对照结果.md) · [诊断总图](output/diagnostics.png) · [四例原片抽帧](examples.jpg)

## 车间里多出的第二个人

提示词要求一名女子独自在车间挥锤。种子 34001 的原片在 22.25–23 秒出现工作台后的第二个人。对应的第 91 个潜在帧（从 0 编号）覆盖解码帧 361–364。以第 363 帧手工框出第二个人可见的头部和上身，框内有 54 个空间位置。23.06 秒的压缩中，第 0 层从这帧选了 1,155 个 token，占可选历史预算的 **37.02%**。框内 54/54 入选，框外 1,101/1,506 入选。全 30 层有 24 层的框内保留率高于框外。人物框含有少量背景，随镜头运动也会移动，以下区域统计限于这个来源帧。[位置叠图](output/diagnostics.png) · [原尺寸参考帧](workshop-363.png) · [逐层框内外计数](output/34001/workshop-region.csv)

| 压缩发生时刻 | 第 0 层仍留的 token | 第 0 层框内 token | 仍留有该帧的层数 | 全层剩余 token 槽位总数 |
|---|---:|---:|---:|---:|
| 23.06 秒 | 1,155 | 54 | 29/30 | 18,353 |
| 24.56 秒 | 0 | 0 | 20/30 | 345 |
| 26.06 秒 | 0 | 0 | 15/30 | 226 |
| 27.56 秒 | 0 | 0 | 14/30 | 225 |
| 29.06 秒 | 0 | 0 | 14/30 | 225 |

在 23.06 秒这一块，第 0 层采样 query 实际分给整帧 91 的自注意力是 **2.67%**，分母为清洁上下文更新时的全部可读键。37.02% 的分母则是压缩时 3,120 个可选名额。两个数共同说明了这帧占了多少槽位、随后获得多少注意力。第 0 层直接保留约 1.5 秒，其他层最后还有少量槽位。已有日志无法测出这帧经后续生成内容间接传播的因果效应。[各次压缩的去留与读取](output/workshop-survival.csv)

**整帧锚点能否识别异常**。在 23.06 秒同一层的可选历史区域内，将各来源帧按相似度从低到高排序。全层中位数显示，第 91 帧对首帧相似度在第 **63.6** 百分位，对完整提示词在第 **50.0** 百分位。30 层中分别有 0 层和 1 层落入各自后 10%。单看抓住 37% 名额的第 0 层，这两个百分位是 **62.5、72.5**。降低与首帧或文本相似度偏低的整帧权重，难以针对这个案例。[逐层相似度及同轮排名](output/anchor-ranks.csv)

只看第二人所在的小框，对首帧同位置区域及完整提示词的全层中位数降至第 **26.8、19.9** 百分位。但取这条视频较早压缩中同龄的候选帧，两个指标的全层中位数也曾低至第 **2.0、7.2** 百分位。人物位置和镜头变化都会影响这个框。另把文本限定为描述主体的 “solitary woman”，异常区域反而位于第 **89.8** 百分位。这项特征度量不足以检查人物数量，单例也不足以给出检测阈值或统计显著性。[同龄对照与排名范围](output/findings.json)

## 楼梯跳景之前的 Sink 注意力

Sink 是固定保留的最初 10 个潜在帧。楼梯两个种子的末段光流分别为 99.81 和 91.83 像素/采样帧对。种子 24017 在约 28.125–28.50 秒逐渐失去窗框，人物脚下转为开阔的城市高处。34017 在同时段仍处于室内。下表按真实视频帧给出生成块覆盖的时段，注意力为 30 层的均值。[每 0.125 秒的两种子原片](stairs.jpg)

| 视频时段 | 跳景 24017 | 室内 34017 | 共同的 Sink 槽位占比 |
|---|---:|---:|---:|
| 26.06–26.75 秒 | 9.77% | 10.93% | 62.50% |
| 26.81–27.50 秒 | 12.05% | 11.49% | 52.63% |
| 27.56–28.25 秒 | 10.50% | 11.12% | 62.50% |
| 28.31–29.00 秒 | 11.47% | 11.63% | 52.63% |

每隔一个生成块发生一次压缩，可读槽位数随之交替。按同一压缩阶段比较，跳景种子从 26.06–26.75 秒到 27.56–28.25 秒，Sink 注意力**升了 0.73 个百分点**，对照种子升了 0.19。再往前一组同阶段比较，跳景种子升了 1.68 个百分点。这一病例没有呈现可作预警的全网 Sink 注意力骤降。采样的时间分辨率为每 3 个潜在帧一次，单头和更短时段的波动仍有可能。[全 30 层从头到尾的 Sink 热图](output/sink-all-layers.png) · [同阶段配对变化](output/staircase-paired-changes.csv)

| 层段（从 0 编号） | 读取 token 的归一化注意力熵 | 压缩后保留的有效来源帧数 |
|---|---:|---:|
| 0–9 | 0.544 | 8.31 |
| 10–19 | 0.512 | 11.19 |
| 20–29 | 0.455 | 9.74 |

四条视频两两比较，30 层熵排序的 Spearman 相关为 **0.968–0.987**，来源覆盖排序为 **0.824–0.936**。后者最高的是第 28 层，平均 21.66 个有效来源帧，第 14 层为 11.29。第 0 层恰好有最高的平均 token 熵，却只保留了 4.68 个有效历史来源帧。即使跨视频排序稳定，这些数也只描述当前预算下的行为。增减一个历史槽位对最终视频有什么影响，仍需固定总预算的干预才能回答。[逐层曲线](output/diagnostics.png) · [分层原始数值](output/late-layer-profile.csv)

## 测量与配对

四条原片为车间 34001、楼梯 24017、同提示词的室内对照楼梯 34017，以及与车间末段光流相近的骑车 34079（85.09 对 86.83）。四例均属定向选择的高运动案例。固定原有提示词、种子、权重、推理和淘汰逻辑，每条重放 489 帧。每块在原版最后一次清洁上下文更新时，取 3 个潜在帧各 8 个固定空间 query、全部 12 个头，对实际可读的全部键重算缩放点积 softmax。熵按每个 query 和头分别求取并除以可读键数的自然对数。Sink 质量按原始帧编号累加。[读取探针](replay.py) · [每层每块的记录](output/time-by-layer.csv)

来源覆盖度沿用 $1/\sum_f p_f^2$，其中 $p_f$ 是来源帧占可选历史名额的比例。首帧相似度使用进入旋转位置编码前的自注意力 key，在空间池化后逐头取余弦再平均。文本相似度使用模型原生交叉注意力的视觉 query 与非填充、非特殊文本 key，在每个头和视觉位置取最高文本余弦，再在 48 个规则空间位置或人物框的 54 个位置平均。两项均按来源帧最初生成时的清洁表示计算。按源帧排名时每帧等权，排名队列是当轮历史候选区域中尚有 token 的来源帧。同龄比较固定取该区域最新的来源帧。[分析代码](analyze.py) · [原始观测压缩包](observation-logs.tar.gz)

四例共 4,920 组层与时间读数、2,040 次逐层压缩。与原实验共有的 **204/204** 份来源选择记录完全一致，每条前 21 个潜在帧逐元素一致。两次保存的 MP4 解码后，1,956 帧中仅 3 帧的 RGB 数组完全相同，各视频平均像素绝对差为 1.68–3.23（0–255）。逐帧比较时间戳相同，所有帧按 16×16 分块平均后的亮度空间相关均高于 0.9990。抽看两个事件的成对视频帧，均在相同时刻看到了相同的人物和场景变化。旧实验只保存前 21 个潜在帧，像素差异的来源未定位。四条重放的生成用时共 409 秒，含一次加载和配对核验约 8 分钟。[原片与重放并排](output/pair-events.jpg) · [逐帧对齐数值](output/pixel_alignment.csv)
